# Origem dos recursos

Os oito desenhos de itens, quatro lixeiras e o ícone da aba são SVGs criados para este projeto com apoio de IA generativa (assistente Claude, da Anthropic), conforme o registro da versão original. São recursos do próprio projeto; nenhum veio de banco de imagens.

O código original foi escrito com apoio do mesmo assistente e simplificado nesta versão com apoio do Codex. Não utiliza bibliotecas externas. A interface usa a fonte padrão do sistema.
